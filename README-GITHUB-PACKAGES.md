# GitHub Packages

`JRebirth-Artworks` has no Maven `pom.xml`. It is not published to GitHub Packages.

Library SNAPSHOTs for the JRebirth org are published from:

- `JRebirth-Organization-POM`
- `JRebirth-RIA-POM`
- `JRebirth` (`12.x-dev`)
- `JRebirth-Skin`
- app/demo repositories that contain a Maven build

See `JRebirth-Organization-POM/.github/` for the reusable snapshot workflow and Maven settings.
