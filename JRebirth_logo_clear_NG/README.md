# JRebirth – déclinaisons du logo

Contenu du pack :
- le dernier logo validé
- fond transparent
- exports en PNG et WEBP
- largeurs : 32, 64, 128, 256, 512, 1024, 1920 et 3840 px

## Dossiers
- `png/` : versions PNG transparentes
- `webp/` : versions WEBP transparentes
- `previews/preview-checkerboard.png` : aperçu sur damier pour vérifier la transparence

## Nommage
Exemple : `jrebirth-phoenix-logo-transparent-1024w.png`
