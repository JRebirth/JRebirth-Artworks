# JRebirth — Phoenix Application Framework Logo

The pack includes the original uploaded image and resampled PNG / WEBP exports without cropping or distortion.

## Files

- `Original/` — Original user image (672 × 710 PNG).
- `PNG/` — Lossless PNG files, several widths.
- `WEBP/` — High-quality compressed WEBP files, several widths.

## Usage

- 32–128px: thumbnails / small graphics. Because the original includes lettering, it becomes hard to read at small sizes.
- 256–512px: website cards and previews.
- 1024px: standard screen display.
- 1920px / 3840px: large display and high-pixel-density assets.
- WEBP is recommended for the website to reduce loading time. PNG is useful for editing and lossless delivery.

**Quality note:** the uploaded source measures 672 × 710 pixels. The larger files are resampled (upscaled) with Lanczos filtering and gentle sharpening; this produces larger files but cannot restore detail missing from the source. Original dark background is preserved (not transparent).
